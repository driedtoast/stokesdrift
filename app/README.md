# stokesdrift Web App

Preact + Vite + Tailwind CSS management dashboard for stokesdrift.

## Tech Stack
- **Preact** — lightweight React alternative
- **Vite** — fast dev server and build
- **Tailwind CSS 4** — styling with Surf Daybreak design system
- **Preact Signals** — reactive state management

## Setup

```bash
# Install dependencies
npm install

# Start dev server
npm run dev

# Build for production
npm run build
```

## Features
- Item CRUD with custom fields
- Location management with GPS zones
- Team-based collaboration (via API)
- QR code view for each item
- Search/filter on items and locations
- Responsive design matching mobile app
